# ARC V13.51.8.14｜印章送刻

新增「印章送刻」分頁：
- 欄位：送刻日期、部門、行政、雇主 / 部門、姓名 / 內容、印章種類、規格 / 備註、數量、單價、金額。
- 木頭章預設 $40。
- 連續章（姓名章）預設規格：長 1.2 × 寬 0.8。
- 藍色連續章預設規格：不加框、長 3 × 寬 1。
- 特殊印章 / 連續章單價可依實際報價輸入。
- 可依行政列印簽收單（每位行政自動分頁）。
- 計算一部、二部印章數與金額。
- LINE 訊息預覽與一鍵複製。
- 已送刻可建立批次，保留批次紀錄、明細、LINE 訊息與簽收單補印。
