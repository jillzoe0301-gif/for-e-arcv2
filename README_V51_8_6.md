# ARC V13.51.8.6

## 本次調整

1. 案件查詢視覺統一
   - 案件編號、雇主/工人、團號建立一致文字層級。
   - 收件編號、外字五碼、經手人編號改為一致標籤/值排列。
   - 申請項目與金額維持醒目，但字體、間距統一。
   - 申請/收費日期、傳真/領件日期使用一致上下排列。
   - 修改、刪除按鈕統一高度、寬度、圓角與字級；以藍色/紅色區分功能。

2. 居留案件登記｜單筆
   - 承辦初始值固定為空白，顯示「請選擇」。
   - 仲介別初始值固定為空白，顯示「請選擇」。
   - 清除、送出成功、補登/現場申請完成後回到單筆預設狀態時，也保持承辦/仲介為「請選擇」。
   - 批次送件原本的一鍵承辦/仲介與預設邏輯不受影響。

不需 Supabase SQL。
