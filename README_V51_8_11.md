# ARC V13.51.8.11

本版修正案件查詢欄位過寬問題。

原因：
- 舊版欄位使用 `min-width: max-content`。
- 案件資料依最長字串以 `ch` 動態加寬。
- 既有 case 欄位 CSS 又有多組 `min-width`，加總後超出畫面。

修正：
- 案件查詢改為固定比例欄寬，總和 100%。
- 案件資料 17%，其餘欄位按實際資訊需求分配。
- 不再套用舊 case 欄位 min-width。
- 桌面滿版可一次看到狀態、仲介、案件資料、承辦、收件資料、項目金額、日期與操作。
- 長文字保留 title 提示，畫面不再因單一筆資料把整欄撐開。

不需 Supabase SQL。
