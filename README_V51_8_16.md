# ARC V13.51.8.16

## 印章送刻調整
- 送刻者選單只顯示姓名，不在姓名後顯示 #分機；分機仍會自動帶入。
- 新增印章時送刻日期直接帶今天。
- 行政、部門依登入者自動帶入：
  - 二部：林莞、奕君、佩珊
  - 一部：嘉陽、詩涵、晏婷
  - 若儀：行政帶若儀，部門手動選擇。
- 雇主、工人姓名／內容由使用者輸入。
- 批次貼上日常只需兩欄：雇主｜工人姓名／內容。
- 所有待送刻與已送刻明細都可以再手動修改、調整、儲存或刪除；已送刻批次的部門數量與金額會同步重算。
- 若手動更換行政為已設定人員，部門會自動跟著帶入；仍可再手動修改部門。

本版不需新增 Supabase SQL。
