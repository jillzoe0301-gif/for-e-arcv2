# ARC V13.51.8 更新說明

本次更新重點：

1. 財務對帳確認
- 批次卡片改為更直觀的資訊排列。
- 第一列顯示：展開按鈕 / 批次編號 / 對帳狀態 / 對帳完成時間 / 對帳確認人。
- 第二列顯示：繳費日期 / 繳款人 / 扣款帳戶 / 仲介。
- 第三列凸顯：繳款件數 / 繳款總金額。
- 第四列顯示：備註。

2. 居留證繳費
- 仲介區塊加入底色區分：
  - 灃康：淺綠
  - 乾坤：淺黃
  - 灃禾：淺粉紅
- 讓不同仲介的待繳案件更容易辨識。

3. 居留證案件登記
- 單筆案件登記頁面欄位重新整理，操作更順手直覺。
- 依常用輸入順序優化欄位排列與視覺分組。

4. 其他
- 不需執行 Supabase SQL。
- 部署後版本顯示為 ARC V13.51.8。
